# Denote

Denote is an open source software by [Synctune](https://github.com/synctune-io), focused on local-first software for writing, connected notes, and personal knowledge. We make room for clear thinking while keeping your notes in files you own.

## Core projects

| Repository | Focus |
| --- | --- |
| [denote](https://github.com/denote-io/denote) | A local-first Markdown workspace for macOS, Windows, and Linux. |
| [denote-plugin-sdk](https://github.com/denote-io/denote-plugin-sdk) | The SDK for building Denote plugins. |

## Plugins

| [denote-code-intelligence](https://github.com/denote-io/denote-code-intelligence) | Local language-server and debugger integrations. |
| [denote-emoji-picker](https://github.com/denote-io/denote-emoji-picker) | Search and insert emoji. |
| [denote-json-yaml-viewer](https://github.com/denote-io/denote-json-yaml-viewer) | Structured JSON and YAML viewing. |
| [denote-kanban](https://github.com/denote-io/denote-kanban) | Kanban boards stored as Markdown. |
| [denote-mermaid](https://github.com/denote-io/denote-mermaid) | Mermaid diagrams in Markdown notes. |
| [denote-note-comments](https://github.com/denote-io/denote-note-comments) | Local note and text-range comments. |

More plugins coming soon.
